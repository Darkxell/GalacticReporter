# GalacticReporter
A javascript ESM library to calculate detailed DPS reports for Pirate galaxy

### Running a demo:

A demo html file is available to test the module's exported functions.<br>
This is a testing base for developpers, not a shippable product.<br>
You are expected to know git and javascript. To use this library as an end user, go to Prelude Myzen.

Using python, run the following command at the root of the repository:
```
python -m http.server
```
Then, open the following url in your browser:
```
http://localhost:8000/demo/Demo.html
```
Press F12, or the "open developer console" shortcut of your browser.
